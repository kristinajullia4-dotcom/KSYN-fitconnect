Enterprise Security Architecture

How FitConnect mathematically isolates franchise data and prevents fraud in software.

PostgreSQL Row-Level Security

Every query injects SET LOCAL app.current_tenant_id = [branch_id]. The database kernel enforces tenant isolation.

60s HMAC Optical Passes

Pass tokens rotate every 60 seconds with cryptographic nonces. Replaying a screenshot triggers an instant 409 Conflict.

Blind Cash Drawer Close

Cashiers input drawer counts blindly. The system hides expected cash to eliminate skimming and unrecorded walk-ins.

RA 10173 PII Protection

Front-desk terminals feature active PII masking (j***e@gmail.com) to eliminate shoulder-surfing in public lobbies.
